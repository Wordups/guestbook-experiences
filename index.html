Behind the mirror

The software is already running.

The booths are still renders. The system that runs them is not. These screens come from our working prototype: one app that runs both experiences.

No Wi-Fi required

Built in

Everything runs on site, offline. Venue internet never decides whether a message gets saved.

Every message kept twice

In the build

Each recording finishes on the booth's own storage first, then gets copied to a backup drive. We never delete the original until your delivery is complete.

Only the words glow

Built in

The screen behind the mirror stays true black, so guests see their reflection and a few lines of light. No screen-in-a-box look.

Our attendant sees everything

Built in

A service-side screen shows camera, audio, display, trigger and storage status plus the live message count. Guests never see it.

One cord, zero clutter

In the build

A single power cable goes in the back. Chargers, cables and hardware stay hidden behind the tech wall.

Backup power

Planned

A battery backup so an unplugged cord can't cut a guest off mid-message.
